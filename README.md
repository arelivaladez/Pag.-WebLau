# Página Web Local 🌐

Aplicación web académica con backend en JavaScript y base de datos en SQL Server.

## Descripción

Proyecto académico enfocado en a la gestión de inventarios de una tienda local de ropa. Incluye una interfaz en HTML conectada a un backend en JavaScript que interactúa con una base de datos SQL Server.

## Estado del proyecto

Este proyecto fue desarrollado como parte de mi formación académica y **no está funcional al 100%**. Algunos componentes no están disponibles en este repositorio debido a la pérdida de acceso a un dispositivo de almacenamiento donde se encontraban. El código aquí publicado refleja el alcance funcional que se pudo recuperar.

### Limitaciones conocidas

## Tecnologías utilizadas

- **HTML5** — estructura de la interfaz
- **JavaScript (backend)** — lógica de servidor y conexión a base de datos
- **SQL Server** — almacenamiento y gestión de datos

## Cómo ejecutar el proyecto

1. Clona el repositorio:
```bash
   git clone https://github.com/[tu-usuario]/pagina-web-local.git
```
2. Instala dependencias del backend (si aplica):
```bash
   npm install
```
3. Configura la conexión a tu instancia local de SQL Server en el archivo de configuración correspondiente.
4. Ejecuta el servidor:
```bash
   node [nombre-del-archivo-principal].js
```

## Qué aprendí

- Conexión de un backend en JavaScript con una base de datos relacional (SQL Server)
- Separación de responsabilidades entre frontend (HTML) y lógica de servidor
- Manejo de flujo de datos entre cliente y base de datos
